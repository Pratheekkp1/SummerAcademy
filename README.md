# Radiant Stars Academy: Summer Program Website

Website for **Radiant Stars Academy**, a summer enrichment program ("Educate, Enrich, Empower").

**Live:** https://summer-academy.vercel.app

## Features

- Two pages: home (hero, about, programs, contact) and a detailed **programs overview**
- Responsive design with Tailwind CSS, slide-out mobile menu and smooth-scroll navigation
- **Enrollment inquiry form that saves to Google Sheets** via a Google Apps Script web app, with a sending state and confirmation feedback

## Tech

HTML5 · Tailwind CSS · vanilla JavaScript · Google Apps Script · Vercel
